Build Prompt — Anime Color Match / LUT Transfer Android App

Build a production-quality Android app for copying/migrating color correction from one video edit to another, specifically designed for AMV/video editors.

The core purpose is:
> Take the color grading/color correction from a selected frame of a reference edit and generate a color transformation that can be applied to another video, producing a Cube LUT and/or HALD LUT.

The app must support both automatic color matching and manual After Effects-style Levels/Curves correction.
Do not simplify the concept into basic histogram matching. The matching engine should attempt to reproduce the actual color transformation between corresponding frames.
