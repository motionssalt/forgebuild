# color-match-lut — Prompt History

## 2026-09-29 — Operator instruction (new app build contract)
Build a production-quality Android app for copying/migrating color correction from one video edit to another, designed for AMV/video editors. Core purpose: take the color grading/CC from a selected frame of a reference edit and generate a color transformation applicable to another video, producing a Cube LUT and/or HALD LUT. Key requirements: import reference & target videos without processing them wholesale (thumbnail/scrub navigation, extract selected still frames); two target-frame selection modes (exact frame, or search-within-range with visual range selection); intelligent multi-stage frame matching (coarse luminance/edge/perceptual-hash scan, feature-point matching, spatial verification, best-frame with confidence, tolerant of resolution/aspect-ratio/crop/letterbox/overlay differences, showing the registration/crop); automatic color matching engine (per-channel RGB analysis — black/white points, midtones, contrast, gamma, saturation, hue — beyond naive histogram matching, LUT-compatible output) with LOW/STANDARD/HIGH precision modes that actually change sampling density; automatic result must remain editable; manual After Effects-style Levels and Curves controls (RGB/master + R/G/B channels, channel-isolated visualization, side-by-side reference/target comparison, draggable curve control points, reset/undo); non-destructive effect stacking (add/enable/disable/reset/edit/delete/reorder/duplicate Levels & Curves over the auto match); real-time still-frame preview (never reprocess the video per slider move); proxy video preview with before/after + split-screen; LUT generation baked from the full correction stack, export .cube and/or HALD with precision-appropriate sampling; proper color management (sRGB/Rec.709 gamma, linear where required, float precision, document LUT color space); Android performance architecture (no full-video decode to RAM, hierarchical frame search, GPU/background processing, caching, aggressive memory release); modern Material 3 Expressive UI (home/project setup/frame matching/color match/manual editor screens); before/after comparison modes; never destroy original media; Storage Access Framework saving (no DownloadManager); thorough error handling; strictly separated modules (video ingestion / frame extraction / matching / color analysis / correction model / stack / LUT gen / preview / export).
